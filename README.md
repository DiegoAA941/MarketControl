# MarketControl

MarketControl es una plataforma web desarrollada para la gestión comercial y ventas de una tienda. 
El sistema cuenta con una arquitectura de doble interfaz que optimiza la experiencia del cliente y 
facilita las tareas de gestión interna.

## Características Principales

*   **Interfaz de Usuario:** Permite a los clientes explorar el catálogo de productos y realizar pedidos bajo dos modalidades:
    *   **Servicio de Delivery:** Gestión de pedidos con envío a domicilio.
    *   **Recogida en tienda:** Compra en línea y retiro físico en la sucursal.
*   **Interfaz de Administrador:** Panel de control privado para la gestión de inventario, visualización de ventas y procesamiento de pedidos en tiempo real.

## Tecnologías Utilizadas

*   **Frontend:** HTML5, CSS3, JavaScript.
*   **Backend:** Java y librerías del ecosistema de Java.

## Instalación

Siga estos pasos para clonar el proyecto de forma local utilizando Git Bash:

1. Clone el repositorio en su equipo local:
   ```bash
   git clone https://github.com
   ```

2. Acceda al directorio del proyecto:
   ```bash
   cd MarketControl
   ```
